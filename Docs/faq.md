# Frequently Asked Questions & How to Use

Use this guide for everyday work. For installation prerequisites, open **Help > System Requirements**; for errors, open **Help > Troubleshooting Guide**.

## Choose a workflow

### How do I create an image-collage PDF?

1. Open **Image Collage** and choose image files or a folder. Enable subfolders only when you want to include them.
2. Select **PDF** as the output format. Set the grid and page orientation.
3. Open the paper settings and choose **A4, A3, A2 or custom dimensions**. Use a larger sheet or landscape orientation when a dense row needs more room.
4. Select **Arrange Images** to review placement, pages and text.
5. Apply the arrangement and return to the collage page. Choose an output folder and filename, then export.

Paper-size choices and manual arrangement described here apply to PDF. Word and Excel exports are also available, but have their own output layout; do not assume they reproduce every PDF arrangement or paper setting.

### Can I update captions on several cells at once?

Yes. In the arrangement editor, use **Ctrl+click** to toggle individual cells, **Shift+click** to select a range, or **Ctrl+A** to select occupied cells across pages. Selection commands are also available from the context menu.

Use the shared text controls or **Update text in multiple cells**. Choose whether to change the caption, additional text, or both before applying. Use Undo if you need to reverse the change.

### How can I inspect an image clearly?

Open the original-image preview from the arrangement editor; **F4** opens it for the selected image. Use **Fit** to see the whole image and **100%** to inspect source pixels. Zoom and pan for closer inspection. The image tray uses thumbnails, so it is not the best place to judge fine detail.

### Is the PDF caption real text?

Collage PDF captions and page text are written as PDF text. Text that is already part of an imported photograph, scanned label or rendered BarTender image remains part of that image. Exporting it does not turn those image pixels into editable text.

## Save and continue

### What should I save for future editing?

Save an editable **.npplcollage** layout from the arrangement editor. Use **Open Saved Layout / PDF** to reopen it, or a compatible collage PDF generated by PrintMaster. An arbitrary third-party PDF is not an editable PrintMaster layout.

Layouts record image file references. Keep the original images available and, when moving work to another PC, move the layout and its source-image folder together. A finished PDF can be viewed independently, but reopening its saved arrangement can still require those source files.

### Does autosave replace saving a layout?

No. The collage editor periodically writes a local recovery draft while you work. After an interrupted session, the app may offer recovery; the File menu also has a collage recovery command. Save a named editable layout for work you intend to keep. Recovery drafts are not a backup of the source images.

### What is the difference between a layout and an exported file?

The editable layout preserves arrangement settings and references for later work. An exported PDF is the finished page for viewing or sharing. Save both when you need a deliverable and a convenient way to revise it.

## Extract and format labels

### How do I export BarTender templates as images?

Open **Extract Labels**, choose templates or a source folder, select an output folder, choose **jpg, png or bmp**, set the DPI and start extraction. The app starts BarTender automation when needed; a BarTender window may appear.

Output names use the source template's base name. When different source folders contain identical names, use the folder-preservation option or separate output folders to avoid name collisions. Review the batch result before using the files.

### Which image format and DPI should I choose?

PNG is lossless and is a useful choice for text, line art and barcodes. JPG can introduce compression artefacts; BMP usually takes more space. Follow your approved label workflow and check the actual output at its intended size.

Higher DPI produces more pixels from a rendered template and also increases processing cost and file size. It cannot restore detail missing from an existing low-resolution image or guarantee barcode readability. Verify the final label using the required print and scan checks.

### Can I add borders or padding to existing images?

Use **Format Images**. Choose the source and destination, set padding and border options, then choose **Same as Source** or **PNG (Lossless)** for output. Compare a sample before processing a large batch.

### Does extraction change my original templates?

The extraction workflow opens templates for rendering and closes them without saving changes. Keep approved originals backed up, and review any template that requires external data, a missing font or a particular printer configuration in BarTender.

## Job cards and the image library

### How do I assemble a job card?

Open **Quick Job Card** (called **Job Cards** in Modern UI). Add the relevant artwork to the Products, Cartons and Others lanes, adjust the text options, then choose **Generate Job Card**. The option to open directly in the Freeform Builder controls whether you see the job-card preview first.

Review the result before saving or exporting. Use the editable workspace save command for a job-card project you want to revisit; this is a separate workflow from saving a .npplcollage layout.

### When should I use the library or freeform editor?

Use the **BTW Image Library / Image Library** to search and review indexed label artwork. Configure its source folders and run the library's scanning/indexing controls before relying on search results. Check the selected artwork before using it in a job.

Use **Freeform Designer / Freeform Studio** when a job needs freely positioned elements rather than the collage builder's regular cell grid. The menu labels differ between appearances, but both open the existing editor.

## Appearance and updates

### Where is Settings, and how do I change the interface?

Settings is at the bottom of the sidebar, above **Built by Yatesh Rohit**. Choose **Current UI** or **Modern UI (Preview)** and click **Save preferences**. Changing appearance does not require creating a new job.

Modern UI includes labelled forms, persistent primary actions, separate extraction task views, responsive job-card lanes and an expandable barcode finder. In the library, use **Source folders** to reveal folder lists; processing progress appears while a task is running. Its collage arrangement editor places the image tray below the canvas and selected-image controls on the right.

Choose **Current UI** to return to the existing interface. The main workspaces keep their inputs when you switch. Reopen editor windows to change their workspace layout, saving unfinished edits first if needed.

### Why do I see no update message at startup?

Startup checks are silent when no newer downloadable release is found or the check fails. Open **Help > Software Updates** to view status or retry.

**Download now** saves a verified installer and opens its folder. **Download & install** downloads it and opens interactive setup. Save your work before allowing setup to close running applications. Local review builds may be newer than the latest public release.

## SAP and file handling

### Does PrintMaster upload my images to SAP?

No. It prepares files for your normal SAP DMS workflow. Associate the correct file with the correct Finished Goods code through your company's approved process. SAP configuration and QC approval are outside PrintMaster.

### Do I need the internet for image work?

Local image preparation and layout editing do not require the update service. Startup checks contact GitHub for release metadata; downloading an update also uses the internet. Those update requests do not upload your source images or templates. Network folders, externally linked template data and your SAP workflow can have separate connectivity requirements.
