# Release Notes

Check **Help > Software Updates** for the version of the executable you are actually running.

## Local review build 1.2.0.0 — not published

- Expanded the optional Modern UI to extraction, image formatting, job-card preparation, library presentation and editor windows.
- Added consistent orange actions, Segoe UI typography, labelled fields and rounded controls.
- Split extraction into template selection and filename-search workflows without clearing their values.
- Added persistent workspace actions, responsive job-card lanes and an expandable barcode finder.
- Prioritised library results, with source-folder controls available on demand and progress shown during processing.
- Added a canvas-first Modern collage arrangement: an image tray below the page, with selected-image controls and page navigation on the right.
- Improved Freeform toolbar visibility and shared editor styling.
- Current UI remains available in Settings. Switching reuses the original controls, retaining unsaved values and the existing processing handlers.

Save the interface choice in Settings. Reopen editor windows when you want to change their workspace layout; changing the main interface does not discard their work.

## Scope to keep in mind

- Manual collage arrangement and expanded paper-size choices described in the user guide are PDF features. Word and Excel exports have separate layouts.
- Existing image content remains raster artwork even when a PDF caption is selectable text.
- Editable layouts reference original image files; recovery is not a source-image backup.
- PrintMaster prepares files for SAP DMS; it does not perform direct SAP upload.

For the project's background and author credit, open **Help > About & Version Info**. For how to use a feature, open **Help > FAQ & How to Use**.
