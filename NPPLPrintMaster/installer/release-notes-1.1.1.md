## Consistent PrintMaster branding

The existing gold/orange barcode-and-wrench logo is now included throughout the app:

- Properly sized logos in Current UI and Modern UI sidebars and Software Updates.
- Original multi-resolution application icon for Explorer, windows, taskbar, editor and preview dialogs.
- Branded installer executable, welcome/finish artwork and header logo.
- Matching desktop/Start menu shortcuts and uninstall entry.
- Branding is embedded, so portable copies do not need a separate logo file.

## Downloads

- **NPPLPrintMaster-Setup-1.1.1.0.exe**: install or upgrade. Save open work before allowing setup to close applications.
- **NPPLPrintMaster-Portable-1.1.1.0.zip**: extract the entire ZIP and open NPPLPrintMaster.exe, keeping its DLLs and subfolders together.

Requires Windows and .NET Framework 4.7.2 or newer. Version 1.1 users can find this release in Help > Software Updates. Older versions need a one-time manual upgrade.
