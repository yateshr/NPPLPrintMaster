## Downloads

- **NPPLPrintMaster-Setup-1.1.0.0.exe**: Windows installer. Use this for installation or upgrading an existing copy.
- **NPPLPrintMaster-Portable-1.1.0.0.zip**: Extract the entire ZIP into a folder, then open NPPLPrintMaster.exe. Keep its DLLs and subfolders beside it.

Requires Windows with .NET Framework 4.7.2 or newer.

## Changes

- Checks for updates silently each time PrintMaster opens. Only an available newer release opens the update window.
- Help > Software Updates offers Download now and Download & install. Connection errors and up-to-date messages stay inside this section.
- Installer downloads are checked against the published file size and SHA-256 digest.
- Optional Modern UI preview with updated navigation, dashboard, Settings and collage layout. Current UI remains available in Settings.
- Original-resolution image preview and A4/A3/A2/custom paper sizes for collage PDFs.

This version includes the new updater. Copies older than this release need to be upgraded manually once; subsequent releases can be downloaded and installed from inside PrintMaster.

The installer opens interactively. Save your open work before accepting its request to close running applications.
