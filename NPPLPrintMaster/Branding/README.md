# PrintMaster branding

The original artwork is preserved from BarcodeOffice.ico in the user's existing NPPLPrintMaster project.

- PrintMaster.ico: original Windows icon, with native 16, 24, 32, 48, 64, 128 and 256 pixel variants; used for the executable, window/taskbar icons and installer.
- PrintMaster.png: unchanged 256 pixel artwork with transparency, extracted from that icon for the interface. Sidebar placements are 52 pixels in Current UI and 46 pixels in Modern UI; Software Updates uses 48 pixels. Images fit their bounds without distortion.
- InstallerWelcome.bmp: 328 x 628 welcome/finish panel with the original logo and product name.
- InstallerSmall.bmp: 110 x 110 installer header logo.

AppBranding embeds the icon and PNG in the executable. All application forms derive from BrandedForm so newly opened editor, preview, help, settings and update windows share the same icon. Desktop/Start menu shortcuts and the uninstall entry use the branded executable icon.
